# Project 5 - Linux Users, Groups and Permissions

## Objective
Create users, add a user to a group, and secure a directory using Linux permissions.

## Steps
- Created users `alice` and `bob`
- Created group `developers` and added `alice` to it
- Created `/secure-data` owned by `root:developers` with permissions `770`

## Permissions (770)
- Owner (root): read, write, execute
- Group (developers): read, write, execute
- Others: no access
