# Project 21: CloudWatch Monitoring Dashboard

Visualize performance.

## Steps
1. Reused the 2 EC2s and ALB from project 20.
2. Generated traffic to the ALB with curl.
3. Created dashboard `Project21-Pratham` with widgets: EC2 CPU, ALB request count, healthy hosts, EC2 network in (`dashboard.json`).
4. Verified the graphs in the CloudWatch console.
